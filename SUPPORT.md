# Getting help

Different questions belong in different places. Picking the right one gets you an
answer faster.

| I want to…                      | Go to                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| Ask how something works         | [Discussions](https://github.com/gmtigrisva123/Chesstrophy/discussions)                       |
| Report a bug                    | [New issue → Bug report](https://github.com/gmtigrisva123/Chesstrophy/issues/new/choose)      |
| Report an accessibility barrier | [New issue → Accessibility](https://github.com/gmtigrisva123/Chesstrophy/issues/new/choose)   |
| Request a feature               | [New issue → Feature request](https://github.com/gmtigrisva123/Chesstrophy/issues/new/choose) |
| Report a security vulnerability | [Privately, per SECURITY.md](SECURITY.md) — never a public issue                              |
| Contribute code                 | [CONTRIBUTING.md](CONTRIBUTING.md)                                                            |

## Before you ask

Most setup problems have a known answer in
[docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md). It is worth thirty seconds.

If that does not cover it, a good question includes:

- What you were trying to do
- What you did, precisely enough to repeat
- What happened instead
- Your Node version (`node --version`), OS, and browser
- Any console or terminal output, as text rather than a screenshot

## Response times

This is a volunteer-maintained project. Issues and discussions are usually
triaged within a week. Security reports are handled on the schedule in
[SECURITY.md](SECURITY.md).

A quiet issue has not been ignored — a comment is always fine if something has
gone stale.
